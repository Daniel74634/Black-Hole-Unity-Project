DT / ET - BINARY BLACK-HOLE EXHIBIT PROTOTYPE
Windows x64 demo submission - 6 October 2026

START HERE
1. Right-click the ZIP and choose "Extract All".
2. Open the extracted DTET_Prototype_Demo folder.
3. Double-click START_DEMO.cmd. No Unity Editor or project import is needed.
   You can also run Demo\DTET_Prototype.exe directly.
4. Press V to raise the wrist controls. Left-click buttons on the wrist.
   Press H to approach the learning board. F/Home returns to the exhibit.

REQUIREMENTS
Windows 10/11, 64-bit; a DirectX 11-capable graphics device; mouse and keyboard.
The extracted package includes Unity's runtime and managed dependencies.
This is a local/offline demo. It is not a headset-ready VR build.
Only the packaging workstation has been tested, not a clean second computer.

WHAT IS IN THIS FOLDER?

Keep the complete Demo folder together. Do not move just the executable out of it.
No Unity project source, Library/cache, old builds, backups, debug symbols,
screenshots, raw recordings or audit logs are included.

EXIT AND RECOVERY
Space: pause/resume. Esc: pause (it does not exit).
Use the wrist EXIT button, the window close button, or Alt+F4 to close the app.
F/Home recovers the overview. R resets playback. O opens wrist input options.
If a launch fails, check that you extracted the entire ZIP and kept Demo intact.
Windows may show an unsigned-app warning; this package is not code-signed.
Use your institution's normal software review process rather than disabling
security protections. The package does not require administrator rights.

IMPORTANT
Motion and chirp graphics are illustrative. Light bending is approximate.
Merger, physical orbit evolution, redshift, clock rates and a live AI tutor are
not implemented here. Read the guide before presenting scientific claims.
