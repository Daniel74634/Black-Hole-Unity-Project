DT / ET PROTOTYPE - CONTROLS AND PRESENTATION GUIDE

VISITOR / VIEW
W/A/S/D      Move around the exhibit
Q / E        Move down / up
Shift        Move faster
Right-drag   Look around
Mouse wheel  Move closer / farther (default is 3x the original sensitivity)
F / Home     Return to the event overview
C            Switch free movement / optional orbit inspection
V            Raise / lower the emulated wrist
Left-click   Operate visible world-space buttons and sliders
O            Wrist options: mouse-look / scroll sensitivity; reset defaults
U            Hide / restore the partner interface

PLAYBACK AND LEARNING
Space        Pause / resume
Esc          Pause
R            Reset
B            Toggle dimming
H            Open / approach the learning board; press again to hide it
T            Approach the information panels
1 / 2 / 3    Story / Graph / Model learning layers
K            Approach the future clock comparison card
J            Pause and align a fixed background star behind a marker
L            Toggle approximate bending
G            Toggle thin-lens broken-ray guides
Alt+F4       Close the window (or use wrist EXIT)

The wrist provides replay, pause/play, rate, Start/Halfway/End seek, overview,
information, learning, dim, orbit, lens, ray, alignment, options and exit buttons.
The learning board provides two starting scenarios, a bounded initial-separation
slider and APPLY START, seek, playback rate and a prediction question with feedback.
Changing visual playback rate does not change a physical wave frequency.
Sensitivity preferences are saved locally for the next visit.

SUGGESTED 2-MINUTE WALKTHROUGH
1. Look around and use the wheel to approach and withdraw. Change height to see
   the bodies from above. F/Home returns to the default visitor pose.
2. V raises the wrist. Pause, seek halfway and replay. O opens input options.
3. H approaches the learning board. Compare A/CLOSER with B/WIDER. Change the
   next initial separation and press APPLY START. Adjust seek and playback rate.
4. Try the prediction question. Switch Story, Graph and Model; try dimming.
5. F/Home returns to the exhibit. J aligns the golden fixed star. L compares
   bending off/on; G displays guides. Move slightly sideways to change its images.
6. T shows the illustrative waveform and scripted guide. K shows clock placeholders.
7. V raises the wrist; End shows the conceptual remnant. Replay starts again.

MODEL AND HARDWARE LIMITS - SAY THESE CLEARLY WHEN PRESENTING
The audience is university students across different knowledge and interest levels.
This is visual exhibit staging with desktop emulation of visitor/head/wrist poses.
It does not have tracked headset or hand/controller support in this build.
The two bodies follow deterministic authored motion, not a coupled physical orbit.
The graph and waveform are illustrative, not measured strain or computed Hz.
The luminous disks and body markers are artistic, not ray-traced horizons.
Stars have fixed source objects; apparent images use a live approximate thin-lens
model in authored units. This is not binary numerical-relativity ray tracing.
The ray guides are broken thin-lens constructions, not full curved GR geodesics.
Redshift and proper-time clocks are not connected; unavailable fields say so.
The guide is local scripted narration, explicitly OFFLINE STAGING / NOT AI.
The single remnant is a conceptual endpoint, not simulated merger or ringdown.
A separate tested physics model exists in the development repository but is not
bound to this runtime. It is not included as an unused submission dependency.
Headset comfort/performance, accessibility, cross-machine compatibility and
learning effectiveness still require hardware and participant validation.
